# 🌷 PlanMyDay

A cute and interactive personal day planner built using **HTML, CSS, and JavaScript**.

PlanMyDay helps users organize their day, manage tasks, stay hydrated, track their mood, and stay motivated — all in one simple and aesthetic interface.

## ✨ Features

- 🌸 Personalized welcome message
- 📅 Displays the current date
- ⏰ Time-based personalized messages
- 🌷 Daily routine planner
- ✨ 10 motivational quotes with Previous/Next navigation
- 📝 Add, complete, and delete tasks
- 📚 Task categories such as Study, Work, Personal, Chores, Creative, and Self-care
- ⭐ Task priority selection
- ⏱️ Task duration selection
- ✨ Automatic daily schedule generation
- 🔔 "What's Next?" task reminder
- 💧 8-glass water tracker
- 💬 Personalized hydration messages
- 😊 Mood check-in with personalized messages
- 📊 Daily progress tracker
- 🍅 25-minute focus timer
- 🌙 End-of-day reflection
- 🎉 Completion celebration
- 🌅 Plan Tomorrow feature
- 🌙 Dark mode
- 💾 Saves information using browser Local Storage
- 📱 Responsive design for different screen sizes

## 🛠️ Technologies Used

- **HTML5** – Website structure
- **CSS3** – Styling, layout, animations, and responsive design
- **JavaScript** – Interactivity and functionality
- **Local Storage** – Saving user information in the browser

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.

You can also use **Live Server** in VS Code for development.
